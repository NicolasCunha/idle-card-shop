# UI copy

Buttons and labels are short and direct. The UI never explains itself.

- Verb + object, or verb + number: `Buy booster`, `Open 10`, `Price 3`, `List 5`, `Hire`, `Train`.
- Status in two or three words, lowercase: `no packs`, `showcase full`, `training`, `cash reserve`.
- No sentences on buttons, no "Click here to...", no instructions in panels, no exclamation marks.
- Mechanic explanations live only in the tutorial (`.claude/rules/tutorial.md`) and in tooltips.
- Numbers formatted consistently: money as `$1,234.50`, short form for large values (`$12.4K`).
- Rarity is never shown by color alone: color plus a letter or symbol (C, U, R, H).

Before adding any string, ask: would a player who has seen this screen once miss it if it were gone? If not, cut it.

# Design pillars (guardrails for every feature)

From GDD sections 1 and 2. A feature that breaks one of these needs Nicolas's explicit approval.

- **Calm.** No timers that pressure, no queues, no impatient customers, no shop hours, no loss while away. **[PENDING GDD Q2]** no staff salaries (provisional).
- **Manual to automatic.** Every loop step can be done by hand first and by staff later.
- **True idle.** Offline time is simulated 100%, with the same tick function as live play. No cap, no penalty.
- **Deterministic market.** Daily prices come from a hash of (seed, card, day). Same day, same price. Nothing about the market is stored in the save. **[PENDING GDD Q3]** global seed (provisional) vs per save.
- **In-game rewards only.** No real money, ads, nagging notifications, or punishment for leaving.
- **Accessible.** Rarity never by color alone; "Reduce motion" honored everywhere; readable contrast in both themes.

Out of v1 scope unless Nicolas says otherwise: scenery graphics, multiplayer, online accounts, monetization, Magic and any collection beyond Base Set, prestige (**[PENDING GDD Q6]**), customers buying sealed boosters (**[PENDING GDD Q4]**). Collection milestones are proposed but not approved (**[PENDING GDD Q5]**).

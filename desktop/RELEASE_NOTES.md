IdleCardShop for Windows and Linux, built with Godot 4.7.2.

2.1.0
- Updates itself: the game checks for a new version at start and downloads only what changed.
- Window, borderless or fullscreen, and window sizes from 800x600 to 1920x1080 (Settings).
- Card detail: the card turns with the mouse.
- Bigger, sharper cards in the Binder.
- Smoother Staff tab and job bars; the Market computes prices in the background.

Unzip and run `IdleCardShop.exe` (Windows) or `IdleCardShop.x86_64` (Linux). Keep the `packs` folder next to the game: it holds the card images. Import your browser save in Settings.
